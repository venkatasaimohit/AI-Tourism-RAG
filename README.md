# AI Tourism RAG Planner

## Overview

An AI-powered travel planner that generates personalized travel itineraries using Retrieval-Augmented Generation (RAG).

- TypeScript
- Tailwind CSS
- shadcn/ui

- PostgreSQL

### Deployment

- Railway

## Features

- AI itinerary generation
- Weather-aware planning
- Budget planning
- Interactive maps
- Hotel recommendations
- Restaurant recommendations
